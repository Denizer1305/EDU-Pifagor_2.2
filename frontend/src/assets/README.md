# Assets проекта «Пифагор»

Папка `src/assets/` хранит статические ресурсы frontend-части образовательной платформы «Пифагор»: логотипы, фирменные иконки, изображения, иллюстрации, аватары и документы.

Assets не должны смешиваться с Vue-компонентами, страницами, сервисами или бизнес-логикой. Эта папка отвечает только за визуальные и медиа-ресурсы проекта.

---

## Структура

```text
src/assets
 ┣ avatars
 ┣ brand
 ┃ ┣ icons
 ┃ ┗ logo
 ┣ documents
 ┣ illustrations
 ┗ images
```

---

## `brand/`

Папка для ресурсов бренда платформы.

Сюда относятся:

- логотипы;
- фирменные иконки;
- брендовые декоративные элементы;
- графика, напрямую связанная с айдентикой «Пифагора».

### `brand/logo/`

Хранит логотипы платформы и связанные с ними варианты.

Примеры:

```text
src/assets/brand/logo/logo.svg
src/assets/brand/logo/icons.svg
src/assets/brand/logo/hero-logo.svg
src/assets/brand/logo/Anastasia.svg
```

Правила:

- логотипы не переименовывать без необходимости;
- не хранить здесь фотографии, баннеры или скриншоты;
- если появляется новый вариант логотипа, он должен иметь понятное имя: `logo-dark.svg`, `logo-light.svg`, `logo-icon.svg`.

### `brand/icons/`

Хранит фирменные SVG-иконки интерфейса.

Основной набор иконок платформы находится здесь:

```text
src/assets/brand/icons/rounded/
```

Иконки используются для интерфейса, навигации, карточек, действий и статусов.

---

## `images/`

Папка для обычных изображений: фотографии, баннеры, изображения партнёров, отзывы, изображения курсов и другие визуальные материалы.

Рекомендуемая структура:

```text
src/assets/images
 ┣ public
 ┃ ┣ hero
 ┃ ┣ partners
 ┃ ┣ testimonials
 ┃ ┗ teachers
 ┣ courses
 ┣ dashboard
 ┣ profile
 ┗ placeholders
```

Что хранить в `images/`:

- фотографии преподавателей;
- изображения отзывов;
- фотографии партнёров;
- изображения курсов;
- баннеры;
- preview-картинки;
- заглушки для карточек.

Что не хранить в `images/`:

- SVG-иконки интерфейса;
- логотипы;
- системные pictogram-иконки;
- документы.

---

## `illustrations/`

Папка для иллюстраций, декоративных сцен и empty-state графики.

Примеры:

```text
src/assets/illustrations/empty-states/
src/assets/illustrations/errors/
src/assets/illustrations/auth/
src/assets/illustrations/public/
```

Сюда можно класть:

- иллюстрации пустых состояний;
- изображения для страниц ошибок;
- декоративную графику авторизации;
- обучающие иллюстрации.

---

## `avatars/`

Папка для аватаров пользователей, демонстрационных профилей и временных изображений персон.

Примеры:

```text
src/assets/avatars/default-student.webp
src/assets/avatars/default-teacher.webp
src/assets/avatars/default-parent.webp
```

Правила:

- реальные персональные фотографии не добавлять без необходимости;
- для демонстрационных данных использовать нейтральные изображения;
- для дефолтных аватаров использовать понятные имена.

---

## `documents/`

Папка для статичных документов, шаблонов и PDF-файлов, которые относятся к frontend-части.

Примеры:

```text
src/assets/documents/privacy-policy.pdf
src/assets/documents/personal-data-policy.pdf
src/assets/documents/templates/
```

Не хранить здесь backend-документацию, миграции, технические отчёты или временные файлы разработки.

---

## Форматы файлов

| Тип ресурса | Формат |
|---|---|
| Иконки интерфейса | `.svg` |
| Логотипы | `.svg` |
| Фотографии | `.webp`, `.jpg` |
| Иллюстрации | `.svg`, `.webp`, `.png` |
| Документы | `.pdf`, `.docx` |
| Заглушки | `.svg`, `.webp` |

---

## Правила именования

Используем `kebab-case`.

Хорошо:

```text
course-card-placeholder.webp
teacher-avatar-default.webp
journal-empty-state.svg
user-settings-icon.svg
```

Плохо:

```text
CourseCardPlaceholder.webp
teacher photo final 2.png
IMG_2345.jpg
иконка новая.svg
```

## Правила использования assets во Vue

Если ресурс лежит в `public/`, он подключается абсолютным путём:

```vue
<img src="/assets/image/logo/logo.svg" alt="Пифагор" />
```

Если ресурс лежит в `src/assets/`, его лучше импортировать внутри компонента или использовать через централизованную карту ресурсов.

```js
import logo from "@/assets/brand/logo/logo.svg";
```

```vue
<img :src="logo" alt="Пифагор" />
```

Для фирменных иконок рекомендуется использовать компонент:

```vue
<BaseIcon name="course" />
```

А не вставлять SVG-файлы вручную в каждом компоненте.

---

## Главное правило

Assets должны быть разложены по смыслу:

```text
brand/icons     — фирменные иконки интерфейса
brand/logo      — логотипы и брендовые знаки
images          — фотографии и обычные изображения
illustrations   — иллюстрации и empty states
avatars         — аватары
documents       — документы и шаблоны
```

Если ресурс используется как часть интерфейса — это, скорее всего, `brand/icons`.

Если ресурс является фотографией или баннером — это `images`.

Если ресурс является логотипом — это `brand/logo`.
