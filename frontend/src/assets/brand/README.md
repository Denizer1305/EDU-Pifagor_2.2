# Иконки платформы «Пифагор»

Папка `src/assets/brand/icons/` хранит фирменные SVG-иконки образовательной платформы «Пифагор».

Основной набор иконок экспортирован из Figma и находится в папке:

```text
src/assets/brand/icons/rounded/
```

На текущем этапе в набор экспортировано **427 иконок**.

---

## Назначение

Иконки используются в интерфейсе платформы:

- в навигации;
- в личных кабинетах;
- в карточках курсов;
- в электронном журнале;
- в заданиях;
- в расписании;
- в настройках;
- в таблицах;
- в кнопках действий;
- в статусах;
- в empty-state блоках;
- в административных разделах.

Иконки являются частью дизайн-системы проекта, поэтому их нельзя хранить вперемешку с изображениями, фотографиями или иллюстрациями.

## Почему иконки лежат не в `images/`

Иконки — это не изображения контента, а часть интерфейса и дизайн-системы.

Правильно:

```text
src/assets/brand/icons/rounded/course.svg
src/assets/brand/icons/rounded/journal.svg
src/assets/brand/icons/rounded/settings.svg
```

Неправильно:

```text
src/assets/images/icons/course.svg
src/assets/images/icon1.svg
src/assets/images/new-icons/
```

## Использование во Vue

Не рекомендуется подключать SVG-иконки хаотично в каждом компоненте.

Плохо:

```vue
<img src="@/assets/brand/icons/rounded/course.svg" alt="" />
```

Лучше использовать единый компонент:

```vue
<BaseIcon name="course" />
```

Рекомендуемый путь компонента:

```text
src/components/ui/BaseIcon.vue
```

Компонент должен получать имя иконки и подставлять нужный SVG из набора.

Пример будущего использования:

```vue
<BaseIcon name="course" />
<BaseIcon name="journal" />
<BaseIcon name="settings" />
<BaseIcon name="assignment" />
```

---

## Базовый принцип `BaseIcon`

Компонент `BaseIcon` должен решать задачи:

- единый способ вывода иконок;
- единый размер;
- управление цветом через `currentColor`;
- поддержка `aria-hidden`;
- возможность добавить `aria-label`, если иконка несёт смысл;
- защита от хаотичных путей к файлам.

Пример ожидаемого API:

```vue
<BaseIcon name="course" />
<BaseIcon name="journal" size="24" />
<BaseIcon name="settings" title="Настройки" />
<BaseIcon name="warning" class="text-danger" />
```

## Цвет иконок

SVG-иконки должны быть подготовлены так, чтобы цвет можно было менять через CSS.

Желательно, чтобы внутри SVG использовались:

```svg
stroke="currentColor"
```

или:

```svg
fill="currentColor"
```

В интерфейсе цвет задаётся через CSS:

```css
.icon {
    color: var(--primary);
}

.icon-accent {
    color: var(--accent);
}

.icon-muted {
    color: var(--secondary);
}
```

Не рекомендуется жёстко зашивать цвет в SVG:

```svg
stroke="#394458"
```

Такую иконку сложнее использовать в светлой и тёмной теме.

## Размеры

| Размер | Значение | Использование |
|---|---:|---|
| `16` | 16px | мелкие inline-действия |
| `20` | 20px | кнопки, меню, строки таблиц |
| `24` | 24px | стандартная интерфейсная иконка |
| `32` | 32px | карточки и крупные элементы |
| `48` | 48px | декоративные иконки в блоках |

Рекомендуемый стандарт для интерфейса:

```text
24px
```

---

## Alt, aria и доступность

Если иконка декоративная, она должна быть скрыта от screen reader:

```html
aria-hidden="true"
```

Если иконка несёт смысл без текста, нужно добавить доступное описание:

```vue
<BaseIcon name="warning" title="Предупреждение" />
```

Нельзя оставлять смысловую иконку без подписи или `aria-label`.

## Когда использовать собственные иконки

Фирменный набор `rounded/` нужно использовать в первую очередь для:

- личного кабинета;
- меню ролей;
- карточек курсов;
- электронного журнала;
- заданий;
- расписания;
- профиля;
- настроек;
- административных страниц.

Font Awesome можно временно оставить в публичной части или там, где иконка ещё не подобрана из фирменного набора.

## Что нельзя делать

Нельзя:

- хранить иконки в `images/`;
- вставлять SVG хаотично через разные пути;
- использовать разные стили иконок в одном интерфейсном блоке;
- смешивать фирменные иконки со случайными скачанными наборами;
- добавлять PNG-иконки, если можно использовать SVG;
- менять цвет внутри SVG вручную под каждую страницу;
- называть файлы `icon1.svg`, `new.svg`, `final.svg`.

---

## Что можно делать

Можно:

- добавлять новые SVG в `rounded/`;
- переименовывать иконки под понятные названия;
- группировать иконки по смыслу, если набор станет слишком большим;
- использовать иконки через `BaseIcon`;
- управлять цветом через CSS;
- использовать `currentColor`;
- постепенно заменять Font Awesome на фирменный набор.
